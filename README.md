# Next Gen Leaders

React + Vite + Tailwind CSS.

    npm install
    npm run dev      # local
    npm run build    # production build

## Vercel
Push to GitHub, import the repo in Vercel (Framework: Vite). Build `npm run build`, output `dist`.

## Edit content
Everything lives in `src/data/content.js`. Replace the placeholder email, phone, address and WhatsApp number there.
